# SmartCarbo — React + Vite

## Como executar
1. Extraia a pasta do projeto.
2. Abra a pasta `smartcarbo-react` no VS Code.
3. No terminal integrado, execute `npm install`.
4. Execute `npm run dev` e abra o endereço informado pelo Vite.

## Funcionalidades
- Rotina de refeições compartilhada entre as datas.
- Data selecionada lembrada no navegador.
- Progresso/conclusão individual por dia.
- Adicionar, renomear e retirar refeições.
- Adicionar/remover alimentos e calcular total de kcal.
- Pesquisa de refeições e alimentos.
- Armazenamento local via `localStorage` (ainda sem backend).

A logo utilizada é `public/smartinho.png`.
